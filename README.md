# ServiBeer

A web-based beverage ordering app used by real customers.

The platform allows users to view products and promotions and generate automated orders sent via WhatsApp.

## Features
- Product catalog
- Dynamic promotions
- Interactive interface
- Automatic order generation
- WhatsApp integration
- Responsive design

## Technologies used
- HTML
- CSS
- JavaScript

## How it works
The user selects products from the web interface, and the system automatically generates the order to be sent via WhatsApp.

## How to run
Open `index.html` in your browser.
