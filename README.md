# ServiBeer

A web-based beverage ordering app used by real customers.

The platform allows users to view products and promotions and generate automated orders sent via WhatsApp.

## Features
- Product catalog  
- Dynamic promotions  
- Interactive user interface  
- Automatic order generation  
- WhatsApp integration  
- Responsive design  

## Technologies Used
- HTML  
- CSS  
- JavaScript  

## How it Works
Users select products from the interface, and the system automatically generates an order ready to be sent via WhatsApp.

## How to Run
Open `index.html` in any web browser.
