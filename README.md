# ServiBeer

Aplicación web para pedidos de bebidas utilizada por clientes reales.

La plataforma permite visualizar productos, promociones y generar pedidos automatizados enviados por WhatsApp.

## Características
- Catálogo de productos
- Promociones dinámicas
- Interfaz interactiva
- Generación automática de pedidos
- Integración con WhatsApp
- Diseño adaptable

## Tecnologías usadas
- HTML
- CSS
- JavaScript

## Funcionamiento
El usuario selecciona productos desde la interfaz web y el sistema genera automáticamente el pedido para ser enviado por WhatsApp.

## Cómo ejecutar
Abrir `index.html` en el navegador.
